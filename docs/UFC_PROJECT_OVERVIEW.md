# UFC Betting Intelligence Platform

## Purpose

The UFC Betting Intelligence Platform is a production-oriented analytics system designed to:

1. Predict UFC fight winners
2. Identify positive expected value (EV) betting opportunities
3. Track Closing Line Value (CLV)
4. Automate UFCStats data ingestion
5. Support future prop betting models
6. Provide a centralized dashboard for operational workflows

---

## Core Workspaces

### Betting Board

Primary betting decision workspace.

Responsibilities:

* Live fight predictions
* Market odds integration
* EV calculations
* Recommended bets
* Watchlist management
* Bankroll recommendations

---

### Line Movement / CLV

Market intelligence workspace.

Responsibilities:

* Opening odds tracking
* Current odds tracking
* Closing odds tracking
* CLV measurement
* Beat-closing-line analysis
* Sportsbook movement analysis

---

### Model Lab

Research and development workspace.

Responsibilities:

* Model training
* Model validation
* Backtesting
* Calibration monitoring
* Feature experimentation
* Ensemble testing

---

### Data Maintenance

UFC ingestion control tower.

Responsibilities:

* Dataset health monitoring
* Event discovery
* Event ingestion
* Validation workflows
* Append workflows
* Audit review

---

## Long-Term Vision

Create a fully automated UFC betting intelligence platform capable of:

* Discovering new UFC events
* Ingesting completed fight data
* Updating fighter feature stores
* Producing live betting recommendations
* Tracking market performance
* Continuously improving model quality
